A full-stack Student Management System built using **Java**, **Spring Boot**, **Thymeleaf**, **JDBC**, and **MySQL**. The application allows users to efficiently manage student records through a simple and responsive web interface.

---

## 🚀 Features

- ➕ Add a new student
- 📋 View all students
- ✏️ Update student details
- ❌ Delete student records
- 🔍 Search students
- 💾 MySQL database integration

---

## 🛠️ Tech Stack

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/SariyaNiyaz/student-management-system.git
```

### 2. Open in Eclipse/IntelliJ

Import the project as a Maven Project.

### 3. Configure MySQL

Create a MySQL database.

Update your `application.properties` file:

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/studentdb
spring.datasource.username=your_username
spring.datasource.password=your_password
```

### 4. Run the application

Run

```
StudentAppApplication.java
```

Open

```
http://localhost:8080
```
